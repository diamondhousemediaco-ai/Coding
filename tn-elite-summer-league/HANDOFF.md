## 1. THE VISION (the elevator version)

An elite high-school summer basketball league built like a pro property — the highest
stage you can play on before college. 16 franchises (8 boys / 8 girls teams under 8 shared
franchise brands), statewide tryouts → combine → televised-style draft → a 5-week season
with playoffs, hosted at Belmont University's Curb Event Center + twin-court practice
facility. Inspired by Unrivaled's brand playbook and OTE's stagecraft. The antidote to
AAU fatigue.

**The Feeling (core pitch copy — use verbatim):**
"Eighty of the best girls basketball players in Tennessee. Eighty of the best boys.
One building. Every player earned the jersey through a tryout, a combine, and a draft —
nobody bought a roster spot, so there are no passengers on the floor. When all ten players
in a game are top-of-the-state talent, every possession is contested — the game plays at
college speed because everyone on the floor forces it to. It's college basketball,
arriving two years early. That's the product. Everything else is just how we deliver it."

## 6. TECH NOTES FOR CLAUDE CODE

- Everything is **dependency-free static HTML** — no build system, no framework. Keep it that way unless converting to a real site project.
- `site/` pages are pure static (no JS) — deploy-ready for Netlify/Vercel/any host.
- `pages/budget_model.html` has live JS (input levers → recalc). Its tables are ALSO
  server-baked with base-case values so it renders without JS. If you change default
  values, update BOTH the input `value=""` attrs and the baked table HTML.
- `pages/season_schedule.html` matchups were generated by a round-robin script then
  baked static (generator removed). Circle method, 8 teams, rounds 1–7 + rivalry rematch.
- 2027 dates are calendar-verified (Jun 3 = Thu, Jul 15–17 = Thu–Sat, Memorial Day May 31, etc.).
- Excel: `pip install openpyxl` + LibreOffice recalc if regenerating. PPTX: pptxgenjs.
